# BIM WebGPU 轻量化浏览系统 - 开发任务清单 (To-Do List)

> 本文档基于《开发设计文档》生成，用于指导项目的全周期开发。请按顺序执行。

## Phase 1: 工程初始化与环境搭建 (Initialization)
- [ ] **项目脚手架搭建**
    - [ ] 使用 Vite 初始化 React + TypeScript 项目。
    - [ ] 配置 `tsconfig.json` (启用 strict 模式)。
    - [ ] 配置路径别名 (`@/` 指向 `src/`)。
- [ ] **样式系统集成**
    - [ ] 安装并配置 Tailwind CSS。
    - [ ] 初始化 Shadcn UI (`npx shadcn-ui@latest init`)。
    - [ ] 安装基础组件 (Button, Card, Dialog, Toast, ScrollArea, Separator, Sheet)。
    - [ ] 配置 `index.css` 全局样式 (深色模式变量)。
- [ ] **Docker 环境容器化** 🔴 *Critical Rule*
    - [ ] 编写 `.dockerignore` (排除 node_modules, dist, etc.)。
    - [ ] 编写 `nginx.conf` (支持 SPA 路由 fallback, 正确配置 WASM MIME types)。
    - [ ] 编写 `Dockerfile` (Multi-stage: Build -> Nginx Serve)。
    - [ ] 编写 `docker-compose.yml` (端口映射 3000:80)。
    - [ ] **验证**: 执行 `docker compose up --build` 确保页面能访问。

## Phase 2: 核心引擎开发 (Core Engine)
- [ ] **Three.js WebGPU 环境**
    - [ ] 安装 `three` (v160+)。
    - [ ] 封装 `WebGPUContext` 类 (负责 Renderer 初始化, resize 处理)。
    - [ ] **Feature**: 添加 WebGPU 支持检测逻辑，若不支持显示优雅的错误遮罩层。
- [ ] **场景基础建设**
    - [ ] 实现 `SceneManager` (管理 Scene, Camera, AmbientLight, DirectionalLight)。
    - [ ] 集成 `OrbitControls` 并调优交互手感 (Damping, ZoomLimit)。
    - [ ] 添加辅助网格 `GridHelper` 和坐标轴 `AxesHelper`。

## Phase 3: 模型加载系统 (Loader System)
- [ ] **Loader 基础架构**
    - [ ] 定义 `IBimLoader` 接口。
    - [ ] 实现 loader 状态管理 (Loading Progress, Error Handling)。
- [ ] **IFC Loader 实现**
    - [ ] 安装 `web-ifc-three` 和 `web-ifc`。
    - [ ] 配置 WASM 静态资源拷贝 (Vite plugin `vite-plugin-static-copy`)。
    - [ ] 实现 `IfcLoaderStrategy` (在 Worker 中加载)。
- [ ] **STEP Loader 实现**
    - [ ] 安装 `occt-import-js`。
    - [ ] 配置 OCCT WASM 静态资源。
    - [ ] 实现 `StepLoaderStrategy` (解析 BRep 为 BufferGeometry)。
