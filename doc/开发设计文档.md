# BIM WebGPU 轻量化浏览系统 - 开发设计文档

## 1. 项目概述 (Project Overview)

本项目打造一个基于 **WebGPU** 的高性能 BIM 模型浏览系统。核心聚焦于 **IFC** 和 **STEP** 格式的 Web 端本地解析与渲染。项目采用纯前端架构，容器化交付，追求极致的工程质量与现代化的视觉体验。

## 3. 核心模块设计 (Core Module Design)

### 3.1 3D 渲染引擎 (Engine Module)
位于 `src/core/engine`。
*   **WebGPUContext**: 负责初始化 `WebGPURenderer`。如果浏览器不支持 WebGPU，需抛出明确错误（本项目不强制回退 WebGL，优先展示 WebGPU 能力，但可提示用户升级浏览器）。
*   **SceneManager**: 管理场景图，包括环境光、主光照、GridHelper 等。
*   **CameraControls**: 封装 `OrbitControls`，针对 BIM 场景优化（如平移速度根据缩放级别自适应）。
*   **SelectionHighlighter**: 实现基于 GPU 的高亮机制（Post-processing 或 Emissive 材质替换）。

### 3.2 模型加载系统 (Loader System)
位于 `src/core/bim`。采用 **策略模式** + **Web Worker**。

```typescript
// 伪代码接口定义
interface IBimLoader {
  load(file: File, onProgress: (percent: number) => void): Promise<BimModel>;
}

// 1. IfcLoaderStrategy
// 使用 web-ifc-three 的 WebWorker 模式解析 .ifc 文件
// 输出: THREE.Group (包含 Mesh 和 UserData)

// 2. StepLoaderStrategy
// 使用 occt-import-js 在 Worker 中解析 .stp 文件
// 将 BRep 数据转换为 BufferGeometry
```

### 3.3 状态管理 (State Management)
位于 `src/stores`。
*   **`useModelStore`**:
    *   `modelRoot`: THREE.Group | null; // 当前加载的模型根节点
    *   `structure`: TreeData[];          // 解析出的构件树结构（用于左侧树展示）
    *   `selectedId`: string | null;      // 当前选中的构件 UUID
    *   `properties`: Record<string, any>; // 当前选中构件的属性
    *   `isLoading`: boolean;
    *   `loadProgress`: number;

### 3.4 UI 界面设计 (UI Design)
*   **Layout**: `src/layouts/MainLayout.tsx`
    *   **Sidebar (Left)**: 模型结构树 (Tree View)。支持展开/折叠，搜索构件。使用虚拟列表 (`react-window`) 优化数万节点的渲染。
    *   **Viewport (Center)**: 3D 画布。悬浮工具栏 (Toolbar) 提供：重置视角、剖切开启、线框模式切换。
    *   **Inspector (Right)**: 属性面板。展示选中构件的 Key-Value 数据。
*   **Theme**: 默认 **Dark Mode**，体现“工业软件”的专业感与“未来感”。半透明磨砂玻璃效果 (Backdrop Blur)。

## 5. Docker 交付标准 (Delivery Standards)

严格遵守 `user_rule.md`。

### 5.1 Dockerfile
```dockerfile
# Stage 1: Build
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
# 配置淘宝源加速
RUN npm config set registry https://registry.npmmirror.com
RUN npm ci
COPY . .
RUN npm run build

# Stage 2: Serve
FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]
```

### 5.2 docker-compose.yml
```yaml
services:
  app:
    build: .
    image: bim-webgpu-viewer
    container_name: bim_viewer_app
    ports:
      - "3000:80"
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf # 方便开发调试配置
```

## 6. 开发步骤规划 (Development Roadmap)

1.  **工程初始化**:
    *   使用 Vite 创建 React + TS 项目。
    *   配置 Tailwind CSS 和 Shadcn UI。
    *   配置 ESLint/Prettier 规范。
2.  **Docker 环境搭建**:
    *   编写 Dockerfile 和 docker-compose.yml。
    *   验证一键启动 (`docker compose up`)。
3.  **Core 引擎开发**:
    *   初始化 Three.js WebGPURenderer。
    *   搭建基础场景（网格、光照、控制器）。
4.  **Loader 实现**:
    *   集成 `web-ifc-three` 实现 IFC 加载。
    *   集成 `occt-import-js` 实现 STEP 加载。
    *   实现 Worker 类封装。
5.  **UI 交互开发**:
    *   开发模型树组件 (与 3D 场景双向联动：点击树->高亮模型，点击模型->树节点选中)。
    *   开发属性面板。
    *   实现 Loading 状态和 Toast 错误提示。
6.  **优化与验收**:
    *   性能优化 (Instancing, MergeGeometries)。
    *   UI 美化 (深色模式、动画细节)。
    *   编写 README.md。

## 7. 风险控制

*   **WASM 文件体积**: `web-ifc.wasm` 和 `occt` 库体积较大，需配置 Vite 的静态资源拷贝，确保 Nginx 能正确服务 `.wasm` 和 `.worker.js` 文件。
*   **MIME 类型**: Nginx 需正确配置 `application/wasm` MIME type，否则浏览器无法加载 WASM。

---
**设计总结**: 
本设计完全基于“纯前端 + WebGPU + 容器化”要求，去除了重后端依赖，利用客户端算力（WebGPU + WebAssembly）解决 BIM 轻量化痛点，符合高星开源项目标准。
